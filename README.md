# Tic_Tac_Game

🎮 Tic-Tac-Toe Game  
A simple and responsive Tic-Tac-Toe game built using HTML, TailwindCSS, and JavaScript.  
This project is perfect for learning DOM manipulation, event handling, and game logic in JavaScript.  

✨ Features:  
- Clean UI styled with TailwindCSS  
- Two-player mode (X vs O)  
- Highlights winning combinations  
- Restart game functionality  
- Fully responsive design  

🚀 Tech Stack:  
- HTML  
- TailwindCSS  
- JavaScript
